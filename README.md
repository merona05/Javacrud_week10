③ Weekly Review

Key Learning: Transaction: 여러 기능을 모두 진행한 후 한번에 데이터베이스에 적용하는 것, Dirty checking: 데이터 베이스 작성 시 이전 내용과 현재 내용을 비교하는 기능, Query method: JPA가 기본 제공하는 기능 외에 원하는 기능을 만들 수 있도록 준비된 기능
Problem & Solution: 질문에 대해 답변을 달아야 하는데 뭔지 알기는 알겠지만 내 언어로 만들어서 답변하는 것이 어려웠습니다. 그래서 ai를 활용해 내 이해도를 점검하고 부족한 부분을 재학습 하면서 개념에 대한 이해도를 높였습니다.
Reflection: 이제는 개발이라는 분야도 꽤 역사가 생겨서 편리한 기능이나 자주쓰는 프로그램을 자동적으로 준비해주거나, 오류가 생길 가능성을 미리 막아주는 명령어들이 생겨났다는 것을 느낄 수 있어서 의미 있었던 것 같습니다.
특히 트랜잭션을 코드 한줄로 만들어 두었다는 것이 인상 깊었습니다.

④ AI Usage

ChatGPT - 과제 진행 순서 재정립, 오류 발생시 문제부분 탐색, render, postman 등 외부 프로그램 사용도움, 필요한 라이브러리 검색.
찾아준 오류가 문제가 맞는지 확인하고, 수정해준 코드가 이전 내용과 동일한, 과제 내용과 부합하는 코드인지 체크했습니다.
ai가 정리해준 과제 조건이 맞는지 더블체크하고, ai가 놓친 부분에 대해 확인하였습니다.

AI 사용 비율에 대한 자기 평가: 여러 분야에서 사용했지만 무작정 AI에게 맡기는 것이 아니라 AI가 제시한 답변을 입맛에 맛게 선택하였기 때문에 적당한 수준에서 잘 사용한 것 같습니다.
